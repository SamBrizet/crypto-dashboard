# Crypto Dashboard

Crypto Dashboard es una aplicacion React para monitorear el mercado cripto usando CoinGecko. Incluye dashboard principal, buscador, top gainers, top losers, cambio de moneda y detalle con grafico.

## Descripcion

El proyecto presenta una experiencia responsive con tema oscuro, arquitectura reusable, graficos con Chart.js y fallback local para no romper la experiencia si la API no responde.

## Tecnologias

- React 19
- Vite
- Axios
- React Router DOM
- Chart.js
- react-chartjs-2
- Framer Motion
- React Icons
